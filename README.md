# Part Shift

Браузерная игра в мире PARTSHIFT: сапёр плюс стратегия в реальном времени (по мотивам Keepsweeper).
Стек: TypeScript, Phaser 3, Vite, Vitest. Позже Android через Capacitor.

## Запуск

```bash
npm install
npm run dev      # локально, http://localhost:5173
npm test         # тесты логики
npm run build    # сборка в dist/
```

`?seed=123` в адресе даёт одинаковое поле (удобно для багов).

## Устройство

- `src/core/` — правила игры на чистом TypeScript без движка. Всё тестируется в `tests/`.
  - `state.ts` — вся партия как обычный JSON (сохранения, будущий сервер).
  - `mapgen.ts` — генерация поля по `mapgen.json`.
  - `world.ts` — правила: жители, постройки, бои, части тел, угроза, Демон; 1–4 игрока.
  - `commands.ts` — всё, что может сделать игрок.
- `src/data/design/`, `src/data/text/` — копии таблиц геймдизайнера и текстов сценариста.
- `src/game/` — Phaser: только рисует состояние и превращает касания в команды (графика временная).
- `src/i18n/` — тексты на русском и английском (`?lang=en` для проверки).

Архитектура, онлайн и монетизация: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Правила

Правила режима «Охота на Демона» пишет геймдизайнер в общей папке проекта (`design/MVP_RULES.md`, таблицы `design/data/*.json`).
Код читает только таблицы: `npm run sync-data` копирует их и тексты сценариста (`text/ru.json`) в `src/data/`, а арт художника и листы аниматора (набор под клетку 52: `art/export/x2`, `art/anim/x2`, иконки, портреты) в `src/assets/art/`.

Управление: первое нажатие ставит Командный центр; проведите по клеткам, чтобы копать (по завалу или энергожиле, чтобы разбирать);
долгое нажатие или правая кнопка ставит метку; панель внизу выбирает постройку; нажатие на врага или открытое гнездо отправляет защитников;
нажатие на школу включает и выключает обучение; пробел или кнопка II ставит паузу. Партия сохраняется сама.

При пуше в `main` GitHub Actions прогоняет тесты, собирает игру и выкладывает её на GitHub Pages.

## Android

Обёртка Capacitor 8 в папке `android/` (владелец: роль «Мобильный разработчик»).

```bash
npm run android:sync   # собрать игру и скопировать её в android/
npm run android:open   # открыть в Android Studio (нужны JDK 21 и Android SDK 36)
```

- Полный экран (системные панели выезжают свайпом от края и прячутся сами), только портрет, экран не гаснет во время партии.
- Вырезы и системные панели: холст держится внутри `--safe-area-inset-*` (Android) и `env(safe-area-inset-*)` (браузеры), см. `index.html`.
- Кнопка «Назад»: убирает призрак постройки, иначе ставит паузу; на паузе или экране итогов сворачивает приложение. Игра решает это через `setBackHandler` из `src/platform/native.ts`.
- Уход из вкладки или приложения ставит паузу и сохраняет партию.
- CI (`.github/workflows/android.yml`) собирает debug APK на каждый PR (артефакт `part-shift-debug-apk`), а с `main` выкладывает его в релиз «Android test build» (тег `android-debug`).
- Иконка и заставка временные (S-01 из вырезок художника): `python3 android/tools/make_icons.py <s01.png>`.
