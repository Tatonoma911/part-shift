# Part Shift

Браузерная игра в мире PARTSHIFT: сапёр плюс стратегия в реальном времени (по мотивам Keepsweeper).
Стек: TypeScript, Phaser 3, Vite, Vitest. Позже Android через Capacitor.

## Запуск

```bash
npm install
npm run dev      # локально, http://localhost:5173
npm test         # тесты логики
npm run build    # сборка в dist/
```

`?seed=123` в адресе даёт одинаковое поле (удобно для багов).

## Устройство

- `src/core/` — правила игры на чистом TypeScript без движка. Всё тестируется в `tests/`.
  - `board.ts` — поле, скрытые объекты, четыре канала подсказок, раскрытие с каскадом.
  - `world.ts` — партия: Энергия, жители, очередь раскопки, события для отрисовки.
- `src/data/rules.json` — числа (размер поля, количество объектов, скорость копания). Геймдизайнер меняет их без кода.
- `src/game/` — Phaser: только рисует состояние и превращает касания в команды.
- `src/i18n/` — тексты на русском и английском (`?lang=en` для проверки).

Архитектура, онлайн и монетизация: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Правила поля (текущие)

- Первое нажатие ставит Командный центр; клетки 3×3 вокруг всегда безопасны и открыты.
- Под клетками: гнёзда адаптантов, склады шасси, тайники HeroOut и один Демон (далеко от центра).
- Открытая клетка показывает отдельные числа по каждому типу в 8 соседних клетках; найденный тайник уменьшает числа.
- Провести пальцем по клеткам ставит их в очередь; жители сами идут и копают. Клетки за краем открытой земли ждут, пока до них можно дойти.
- Долгое нажатие или правая кнопка: метка опасности (каскад и очередь её не трогают).
- Вскрытая угроза пока только помечается и перекрывает проход; бои будут следующим шагом.

При пуше в `main` GitHub Actions прогоняет тесты, собирает игру и выкладывает её на GitHub Pages.
