# Окна выбора: Звонок Контроля, голосование, купол и флаг

Статус: в работе. Слияние в main только после «да» Антона в треде «Все пожелания Антона».
Общая система: `design/INTERFACE_SYSTEM.md` (кнопки 48 / 56 / 64 px, одна форма, один шрифт).

## Сделано (код, `src/game/Pulse.ts`, `controlCall`)

- Выбранный ответ остаётся обведённым янтарём. В кооперативе при смене голоса обводка переходит на новый ответ, со старого снимается (раньше обводка оставалась на обоих).
- Цена ответа на фиолетовой кнопке белая (`INK.white`). Прежний лиловый `#E9DDFF` на `#8A4DFF` давал 3,5:1, для текста 18 px жирным нужно 4,5:1; белый даёт 4,6:1.

## Решения, зафиксированные без вопросов

- Цель касания ответов 112 px по высоте и вся плита ответа; кнопки шире 48 px.
- Таймер остаётся полосой и цифрой «N с». Цвет полосы меняется на коралл при меньше 5 с.
- Ответ по таймеру выбирает Контроль (`events.json timeoutChoice`), текст «Вы не ответили. Контроль выбрал за вас. Как обычно.» сохраняется.
