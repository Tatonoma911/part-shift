Обучение, онлайн-лобби, рекорды, поддержка

Четыре экрана, которые не про смену, но без которых игра не работает: карточка-подсказка обучения, лобби онлайн-вызова (2–4 игрока), таблица рекордов, поддержка игры (донат и поделиться).

1. Обучение: карточка-подсказка

Подсказка одна за раз, в углу, не закрывает поле. Три карточки первой смены, потом только по запросу из Справочника. Пропустить можно в любой момент.

  • Подсказка не блокирует поле: тапы идут мимо. Текст только из text/ru.json.

2. Онлайн: лобби вызова (2–4 игрока)

Друг заходит по ссылке на сайт к хосту: P2P через браузер хоста, без своего сервера. Четыре места: занятое, свободное, закрытое (ждём подключения). Кнопка «Начать» только у хоста и только при двух игроках.

  • Ошибка связи показывает, что будет дальше, а не просто «ошибка».
  • Для гостя кнопка «Начать» не показана, а не заблокирована: нечего объяснять.

3. Таблица рекордов

Список мест без прокрутки страницы: топ-5, своя строка всегда видна внизу. Рекорды за смену, не за аккаунт.

  • Своя строка подсвечена тонкой плашкой и цифрой, цвет не единственный признак.

4. Поддержка игры: донат и поделиться

Добровольный донат: 50, 100, 300, 500, 1000 ₽ или своя сумма. Кнопка «Купить разработчику кофе» большая, золотая, на всю ширину. Экран не давит и не мешает игре.

  • Донат никогда не появляется в середине смены и не даёт игровых преимуществ.
  • Проверка. Лобби и таблица на 360 px без прокрутки страницы: список внутри блока. Золотая кнопка доната читается при тёмной теме (контраст 8,4 с тёмным текстом).
