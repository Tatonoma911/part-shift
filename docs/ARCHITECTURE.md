# Part Shift: архитектура

Обновлено 2026-10-09. Решения Антона: онлайн на 2–4 игроков нужен с самого начала, игра бесплатная с рекламой и добровольной поддержкой автора, языки русский и английский.

## Слои

| Слой | Где | Что делает |
|---|---|---|
| Ядро правил | `src/core/` | Чистый TypeScript без браузера и движка: поле, жители, Энергия, бои. Одинаково работает в браузере и на сервере. |
| Команды | `src/core/commands.ts` | Всё, что делает игрок, это объект-команда (`placeCore`, `queueDig`, `cancelDig`, `toggleMark`, дальше `build`, `attack`...). Ввод никогда не меняет состояние напрямую, только через `World.apply()`. |
| Данные | `src/data/*.json` | Числа баланса, их меняет геймдизайнер. |
| Отрисовка | `src/game/` | Phaser: рисует состояние и превращает касания в команды. |
| Тексты | `src/i18n/` | `ru.json`, `en.json`; язык по браузеру, `?lang=en` для проверки. Тест следит, чтобы ключи совпадали. |

## Онлайн на 2–4 игроков

**Выбор по умолчанию: авторитетный сервер на Colyseus (Node.js + TypeScript).**

- Сервер запускает то же самое ядро `src/core`. Клиенты шлют только команды, сервер проверяет их через `World.apply()` и рассылает состояние. Нечестный клиент не может «нарисовать» себе Энергию.
- Почему не «каждый считает сам» (lockstep): математика с плавающей точкой (`Math.hypot`, тригонометрия) может давать разные результаты в разных браузерах, и партии бы расходились. С сервером эта проблема исчезает.
- Colyseus даёт готовые комнаты, подбор игроков, переподключение после обрыва и синхронизацию состояния. Код сервера будет в том же репозитории (`server/`).
- Одиночная игра работает без сервера: тот же `World` крутится прямо в браузере. Так игра открывается мгновенно и работает офлайн.
- Хостинг: небольшой сервер (Fly.io, Railway или VPS, порядка 5 $ в месяц). Бесплатные тарифы «засыпают», и первый вход в онлайн ждал бы десятки секунд. Понадобится, когда дойдём до онлайна; до этого платить не нужно.

Что уже готово: ядро детерминировано (общий сид поля) и управляется только командами. Следующие шаги ядра для онлайна: несколько игроков в одном `World` (у каждого свой Командный центр, жители и Энергия), номер игрока в каждой команде, режим «последний Командный центр стоит».

## Деньги

- **Реклама:** в браузере Яндекс Рекламная сеть (основная аудитория русскоязычная), в Android-сборке AdMob через Capacitor. Формат по умолчанию: добровольный ролик за награду (например, удвоить находку в тайнике), без насильных вставок посреди партии.
- **Поддержать автора:** экран со ссылками (Tribute, карта, криптокошелёк). Ничего не открывает в игре, просто благодарность. Перед выпуском в Google Play сверим, как его правила относятся к внешним ссылкам на донаты, и при необходимости покажем этот экран только в веб-версии.

## Публикация

GitHub Actions на каждый пуш в `main`: тесты, сборка, выкладка на GitHub Pages. Android потом через Capacitor из той же сборки.
